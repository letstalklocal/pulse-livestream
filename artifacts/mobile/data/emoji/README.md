# Bundled emoji catalog

Unicode Emoji 16.0, fully-qualified sequences from https://www.unicode.org/Public/emoji/16.0/emoji-test.txt (2024-08-14). Group order follows the source. Emoji components are omitted; skin-tone and combined sequences are included. Rendered using device fonts; the catalog works offline. Some newer glyphs require current OS fonts.

Data is distributed under the included Unicode license. To regenerate, parse `# group:` headers and `fully-qualified` rows, joining their hexadecimal code points. No user content is sent to Unicode.
